# Data and code availability

## Public derived data

This repository contains de-identified participant-level derived data and summary tables used for the submitted analyses, including spectral-parameterization outputs, posterior/global aperiodic measures, movie Aperiodic-ISC, permitted demographic and symptom variables, EEG quality-control summaries, figure source data and statistical summary tables.

The machine-readable Supplementary Tables submitted to Nature Mental Health are in data/manuscript_tables. An archival DOI will be added when a versioned repository deposit is created.

## Restricted data

Raw primary-cohort EEG and item-level clinical data are not publicly redistributed because of consent, privacy and institutional-governance constraints. Public files must not contain direct identifiers, dates of birth, free-text clinical notes or re-identification keys.

HBN EEG data are not redistributed here. They should be obtained from the HBN EEG BIDS/NEMAR resources under the applicable access terms. The repository contains only the code and permitted derived outputs needed to audit the manuscript analyses.

## Code scope

The repository contains preprocessing, spectral parameterization, resting posterior analyses, Aperiodic-ISC estimation, statistical models, sensitivity analyses and figure generation. Five late-stage analysis families used in the submitted manuscript still require their final scripts and output bundles to be transferred from the analysis workspace. This is transparently tracked in analysis_requests/ANALYSIS_WAREHOUSE_COMPLETION_v6.md.

## Citation and reuse

Reuse should cite the manuscript and the versioned software/data release. Users must comply with the terms of the original HBN data source and must not attempt to re-identify participants.
